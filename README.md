# Atividade de Reposição: Consumo de API com Axios

Aplicativo desenvolvido em **React Native com Expo** que consulta uma API pública usando **Axios** e exibe os dados retornados na tela.

- **Disciplina:** PDMI
- **Referência:** Atividade de 19/10/2026
- **Autor(a):** Beatriz Hermenegildo Egen

## Como executar

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado
- npm

### Passo a passo

1. Clone ou baixe o projeto e acesse a pasta:

   ```bash
   cd AtividadeAxios
   ```

2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o projeto:

   ```bash
   npx expo start
   ```

### Rodando no navegador (web)

Caso não tenha celular ou emulador, instale as dependências web (apenas na primeira vez):

```bash
npx expo install react-dom react-native-web @expo/metro-runtime
```

Depois inicie em modo web:

```bash
npx expo start --web
```

O app abrirá em `http://localhost:8081`.
